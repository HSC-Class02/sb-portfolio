# Solbi's Portfolio

Responsive personal portfolio with four streamlined sections.

## Categories
1. **About** — profile, nursing interests, and links.
2. **Projects & Reports** — AI/data projects, analysis reports, research notes, and study resources.
3. **Activities** — academic experiences, practical learning, teamwork, volunteering, competitions, and extracurricular activities.
4. **Certifications** — certificates, qualifications, and completed courses.

## Structure
```
.
├── index.html
├── reports/         # Projects, AI reports, analysis write-ups
├── readings/        # Study resources and reading notes
├── research/        # Research notes and project documentation
├── activities/     # Academic and extracurricular experiences
└── certifications/  # Certificates and qualifications
```

The folder structure is retained for file organization; the homepage groups the content into four categories for easier navigation.

## Deploy
Enable GitHub Pages in **Settings → Pages**, select the `main` branch and `/(root)` as the source.

## Update
Add files to the appropriate folder and update the matching section of `index.html` with a title, summary, date, and link. Avoid publishing private contact details or personal documents.
