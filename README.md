# Portfolio

A responsive personal portfolio organized by five clear categories.

## Categories
1. **About** — profile, introduction and contact links.
2. **AI Generated Reports** — AI-assisted analysis and data reports.
3. **Curated Readings** — major references, research trends and reading notes.
4. **Research & Activities** — research, projects, extracurricular and volunteer activities.
5. **Certification & Qualification** — certificates, qualifications and completed courses.

## Structure
```
.
├── index.html
├── reports/
├── readings/
├── research/
├── activities/
└── certifications/
```

## Preview
Enable GitHub Pages in **Settings → Pages** and select the `main` branch with `/(root)` as the source.

## Update guide
Add new reports, reading notes, projects and certificates to their matching folders. Then update the corresponding section in `index.html` with a title, short summary, date and link.
